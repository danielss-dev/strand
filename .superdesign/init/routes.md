# Routes

The website uses a zero-dependency static build (`website/build.mjs`), not a client-side router.

| URL | Source | Layout |
| --- | --- | --- |
| `/` | `website/index.html` | Monolithic landing shell in the same file |
| `/docs/` | `website/docs/index.md` | Documentation template generated by `website/build.mjs` |
| `/docs/<slug>/` | `website/docs/<slug>.md` | Documentation template generated by `website/build.mjs` |

The requested target is `/`. Its sections are Hero + interactive app demo, Performance, Complete Git client, Keyboard, Agent review, Accountability, Pricing, Download, and Footer.
